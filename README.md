# Prestigio Weather Kiosk
Minimalny launcher dla Android 5.1 (API 22), uruchamiający stronę stacji pogodowej w Firefox.

Po instalacji naciśnij HOME i wybierz Weather Kiosk. Przy pierwszym otwarciu adresu wybierz Firefox.
Awaryjny powrót: Ustawienia > Aplikacje > Weather Kiosk > Wyczyść ustawienia domyślne, a następnie HOME i wybierz zwykły Launcher.
