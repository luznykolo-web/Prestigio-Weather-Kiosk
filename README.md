# Prestigio Weather Station

Docelowa stacja pogodowa dla Prestigio PMT3027 / Android 5.1 (API 22).

- lokalny interfejs HTML w APK
- dane: Open-Meteo
- pełny ekran / immersive sticky
- ekran stale włączony
- orientacja pozioma
- działa jako zwykła aplikacja i HOME launcher
- bez Firefoksa i bez GitHub Pages do wyświetlania interfejsu

Po instalacji najpierw uruchom aplikację z ikony i sprawdź pogodę. Dopiero potem naciśnij HOME i wybierz `Stacja Pogodowa` jako launcher.
